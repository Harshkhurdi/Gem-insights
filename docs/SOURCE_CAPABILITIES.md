The current import contract is **GeM-only** (`GEM/YYYY/B|R/...`). `source_id` identifies acquisition channels, not separate integrated procurement portals. The new filter is labeled an acquisition-source filter. A CPPP/state ID must not be relabeled as GeM. Future non-GeM analytics need an explicit portal namespace and reviewed cross-portal relationships before combining totals.

Uncertain re-tender relationships are not silently merged.
